🍭 Candy's Castillo — Doceria Encantada
Bem-vindo ao repositório da Candy's Castillo, uma doceria digital com foco em simplicidade, doçura e atendimento humanizado. Este projeto é uma landing page interativa para venda de doces, com integração direta ao WhatsApp e Instagram, desenvolvida com HTML, CSS e JavaScript puro.

✨ Visão Geral
A Candy's Castillo oferece:

Pirulitos — R$ 1,25 cada

Paçocas — R$ 1,00 cada

Combos especiais para presentear ou se deliciar

O site funciona como um catálogo virtual com sistema de pedidos que gera mensagens prontas para envio via WhatsApp e Instagram, facilitando a compra.

🚀 Funcionalidades
🧁 Catálogo de produtos com cards dinâmicos

🛒 Modal de pedido com seletor de quantidade e resumo

💌 Correio Elegante: envie um doce com mensagem personalizada para:

Amizade 🤝

Crush 💕

Aniversariante 🎂

Inimigo Elegante 😈

📱 Botões de contato que abrem conversa direta no WhatsApp ou Instagram

📊 Contadores animados exibindo preços na hero section

🎨 Design com tema pink/doce com partículas animadas no fundo

⏳ Preloader com barra de progresso

🎯 Responsivo para todos os tamanhos de tela

🧩 Popup de boas-vindas com informações sobre entregas (exclusivo para comunidade Senac)
